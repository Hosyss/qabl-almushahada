## القرار

لدينا الآن عشرة أغلفة توضيحية أصلية للأعمال العشرة المنشورة في checkpoint `P4-03C2`. هذه الصور ليست Posters رسمية، ولا Screenshots، ولا نسخًا من تصميمات الاستوديوهات. لا تُستخدم كدليل محتوى ولا تؤثر في قرار الملاءمة.

النص الظاهر للمستخدم:

> غلاف توضيحي أصلي — ليس الملصق الرسمي

## المصدر والتخزين

- الأغلفة السبعة الأولى: وُلدت خصيصًا للمشروع بأداة OpenAI المدمجة في 14 أغسطس 2026.
- أغلفة `P4-03C2` الثلاثة: رسوم هندسية أصلية أُنشئت خصيصًا للمشروع بسكربت رسم deterministic باستخدام Pillow داخل GitHub Actions؛ لا تعتمد على ملف صورة أو Poster أو Screenshot خارجي.
- التخزين: ملفات WebP محلية تحت `public/artwork/`؛ لا hotlink ولا API خارجي وقت التشغيل.
- المقاس: `720×960` بنسبة `3:4`.
- الربط: allowlist ثابتة حسب `titleId` داخل `lib/title-artwork.ts`.
- أي عنوان غير موجود في allowlist يحصل على fallback محايد، ولا يرث صورة فيلم آخر.

## التوجيه البصري المشترك

الأسلوب المشترك هو layered paper-cut / هندسي بألوان المشروع الكريمية والخضراء والبرتقالي الترابي، بلا نص أو شعار أو watermark أو شخصية محمية أو تركيب مطابق لبوستر رسمي.

المشاهد العشرة:

- Cars: سيارة سباق عامة بلا وجه أو شعار على طريق صحراوي.
- E.T.: حديقة ليلية ودراجة ثابتة ومسار ضوء، بلا مخلوق أو مشهد الدراجة أمام القمر.
- Harry Potter 1: مدرسة حجرية خيالية عامة وكتب وفانوس، بلا شخصيات أو رموز السلسلة.
- Minions: أشكال صفراء تجريدية داخل ورشة، بلا وجوه أو نظارات أو تصميم الشخصية.
- Barbie: بيت وردي هندسي وباب إلى عالم أهدأ، بلا دمية أو شعار.
- Jurassic Park: أثر قدم زاحف ضخم وغابة ممطرة وسياج عادي، بلا Logo أو بوابة السلسلة.
- My Neighbor Totoro: طريق ريفي ياباني ومظلة وبلوط، بلا مخلوقات أو مشهد موقف الحافلة الشهير.
- Alice in Wonderland (2010): باب هندسي وطريق متقلب داخل حديقة سريالية، بلا شخصية أليس أو عناصر Disney المميزة.
- The Hunger Games (2012): ساحة دائرية خالية وسط غابة وقت الغروب، بلا Mockingjay أو شعار أو شخصية أو سلاح مميز للسلسلة.
- Spider-Man: No Way Home (2021): مدينة ليلية ومسارات ضوئية متقاطعة نحو بوابة هندسية عامة، بلا Spider-Man أو بدلة أو شعار عنكبوت أو تركيب Poster رسمي.
