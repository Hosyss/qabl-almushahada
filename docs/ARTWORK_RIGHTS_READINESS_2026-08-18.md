# قبل المشاهدة — جاهزية الصور وحقوق الاستخدام

**التاريخ:** 18 أغسطس 2026  
**الحالة:** لا تغيير بصري في هذا checkpoint؛ الهدف تثبيت provenance gate قبل أي استبدال للصور الحالية.

## الحالة الحالية

الصور العشرة الموجودة تحت `public/artwork/` هي الأغلفة التوضيحية المحلية التي أُدخلت للمشروع في PR #67 وPR #69. التطبيق يعلن للمستخدم صراحة:

> غلاف توضيحي أصلي — ليس الملصق الرسمي

الكود لا يستخدم TMDB أو IMDb أو OMDb أو hotlink خارجي للصور الحالية.

هذا الملف لا يحاول تحويل وصف «أُنشئ للمشروع» إلى رأي قانوني في قابلية حماية الرسم نفسه بحقوق نشر؛ هو فقط يسجل منشأ asset داخل المشروع ويمنع خلطه مستقبلًا بصورة خارجية بلا مصدر وحقوق موثقة.

## لماذا لا نستبدل الرسومات بملصقات من الإنترنت الآن؟

المطلوب البصري النهائي هو صور/ملصقات حقيقية للعمل عندما يكون استخدامها مشروعًا ومستدامًا. لكن وجود صورة على الإنترنت أو في API لا يعني أن استخدامها التجاري مجاني.

### TMDB

وثائق TMDB الرسمية تذكر أن developer API مجاني للاستخدام غير التجاري مع attribution، بينما الاستخدام التجاري — ومنه موقع يهدف إلى تحقيق دخل من الإعلانات — يحتاج اتفاقًا تجاريًا مكتوبًا منفصلًا. لذلك لا نستخدم TMDB posters في مشروع AdSense من دون هذا الاتفاق.

### OMDb

شروط OMDb تمنح استخدام المواد/مساهمات المستخدمين لأغراض شخصية غير تجارية، وتمنع بناء عمل تجاري عليها دون تصريح. لذلك Poster API ليس مسارًا مجانيًا مناسبًا لهذا المشروع لمجرد توفر الصورة تقنيًا.

### IMDb

IMDb يوفر بياناته الرسمية عبر AWS Data Exchange وبترخيص/اشتراك؛ حقل الصورة جزء من بيانات العنوان الخاضعة لاتفاق الترخيص. هذا ليس بديلًا مجانيًا تلقائيًا.

### Wikimedia Commons / Wikidata

Commons يسمح فقط بمواد حرة الترخيص أو Public Domain وفق قواعده، ولا يقبل fair-use movie posters. لذلك يمكن استخدام ملف من Commons فقط بعد فحص صفحة الملف والترخيص/الإسناد لكل asset على حدة.

Wikidata لبعض الأعمال الحالية يشير إلى صور حرة مرتبطة بالعمل (مثل صورة أزياء أو مجسم أو logo/title image)، لكنها ليست بالضرورة الملصق السينمائي الرسمي ولا بديلًا بصريًا مناسبًا للبطاقات الحالية. لا نستبدل الغلاف برسمة بصورة أقل صلة لمجرد أنها مجانية.

## الحارس المضاف

`TitleArtwork` أصبح يحمل `provenance` صريحًا:

- `project_created_illustration`: للصور الحالية المنشأة للمشروع.
- `external_rights_cleared`: لأي asset خارجي مستقبلي؛ ويجبر TypeScript على وجود:
  - `sourceUrl`
  - `rightsBasis`
  - `attribution`

لا يغير هذا الحارس العرض الحالي أو D1 أو Decision Engine.

## قاعدة الاستبدال المستقبلية

لا يُستبدل أي غلاف حالي بصورة خارجية إلا إذا كان لدينا، لكل ملف على حدة:

1. رابط مصدر ثابت يمكن مراجعته.
2. أساس استخدام واضح يسمح بنوع استخدام الموقع الفعلي، لا مجرد مشاهدة/تنزيل الصورة.
3. نص attribution إن كان مطلوبًا.
4. إثبات أن asset يخص العمل الصحيح ولا يخلط نسخة/فيلمًا آخر.
5. QA بصري وأداء بعد الاستبدال.

إذا كان المصدر يعتمد على اتفاق تجاري أو شراء ترخيص، فهذا قرار خارجي حرج ويحتاج موافقة صريحة قبل الدفع/التعاقد.

## القرار الحالي

نحتفظ بالأغلفة التوضيحية الحالية بدل استبدالها بصورة خارجية غير مثبتة الحقوق. طلب الصور الأصلية **مفتوح كهدف بصري**، لكن التنفيذ ينتظر مصدرًا يسمح بالاستخدام التجاري/الإعلاني بوضوح أو اتفاق ترخيص مع صاحب المصدر.
