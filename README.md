# قبل المشاهدة

دليل عربي يساعد الأسرة على فهم محتوى الفيلم أو المسلسل قبل تشغيله، ثم يفسّر قرار الملاءمة بدل عرض رقم غامض.

> المشروع في مرحلة **نموذج المنتج + تأسيس الإنچين**. أسماء الأعمال والوقائع الظاهرة داخل الواجهة توضيحية وليست مراجعات منشورة.

## النسخة الحالية

- الصفحة الرئيسية: هوية عائلية هادئة، بحث تجريبي، مبادئ الثقة، نموذج نتائج، شرح المنهج، وحدود الأسرة.
- صفحة مراجعة كاملة: القرار، سببه، محاور المحتوى، الوقائع والتوقيتات، حالة النسخة، والنتيجة المخصصة للأسرة.
- اتجاه عربي كامل `RTL` وتصميم متجاوب للموبايل والكمبيوتر.
- إنچين قرار TypeScript قابل للاختبار، يرفض المصدر الواحد والبيانات الناقصة والتعارضات ولا يخمّن.
- مخطط D1 من 13 جدولًا، تحميل صارم، نشر ذري، وبلاغ يوقف النتيجة مع سجل تدقيق.
- رابط النسخة المنشورة: <https://qabl-almushahada.hosys.chatgpt.site>

## ابدأ من هنا

1. اقرأ [`docs/PROJECT_STATE.md`](docs/PROJECT_STATE.md) لمعرفة آخر حالة مؤكدة.
2. اختر بندًا واحدًا فقط من [`docs/ROADMAP.md`](docs/ROADMAP.md).
3. اتبع [`docs/FREE_PLAN_WORKFLOW.md`](docs/FREE_PLAN_WORKFLOW.md) للتشغيل والعمل بأقل استهلاك ممكن.
4. أي مساعد برمجي جديد يجب أن يقرأ [`AGENTS.md`](AGENTS.md) قبل تعديل المشروع.

## التشغيل محليًا

المتطلبات:

- Node.js `22.13.0` أو أحدث.
- Git.
- يُفضّل WSL أو Git Bash على Windows لتشغيل أوامر الإنتاج الأصلية.

```bash
npm ci
npm run dev:local
```

ثم افتح العنوان الذي يظهر في الطرفية.

### أوامر التحقق

```bash
npm run lint:local
npm run build:local
npm run test:engine
npm run test:migrations
```

أوامر `npm run build` و`npm test` الأصلية مخصصة لمسار نشر ChatGPT Sites وتستخدم أدوات Linux إضافية.

## أهم المسارات

- `/` — الصفحة الرئيسية وتجربة حدود الأسرة.
- `/review` — نموذج صفحة المراجعة الكاملة.

## بنية المشروع المختصرة

```text
app/
  page.tsx            الصفحة الرئيسية
  review/page.tsx     المراجعة الكاملة
  globals.css         الهوية والتجاوب لكل الصفحات
public/
  hero-grove.webp     الرسم الرئيسي المضغوط
lib/review-engine/    نموذج المجال، بوابات الجودة، والقرار
db/                   مخطط D1 وخدمات التحميل والنشر والبلاغ
tests/                اختبارات الإنچين والحالات الخطرة
docs/
  PROJECT_STATE.md    آخر حالة مؤكدة
  ROADMAP.md          خطة التنفيذ
  FREE_PLAN_WORKFLOW.md طريقة الاستمرار بأقل تكلفة
```

## قاعدة المنتج الأهم

الإنچين لا يقرر هل العمل «جيد» أو «سيئ». المراجع البشري يسجل وقائع منظمة من نسخة محددة، ثم يطبق النظام حدود الأسرة على هذه الوقائع. لو البيانات ناقصة أو متعارضة، النتيجة الصحيحة هي **«البيانات غير كافية»** وليست «مناسب».
